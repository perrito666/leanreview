# VS Code support for leanreview files

A minimal extension covering both leanreview file kinds:

- `*.review.json` (review exchanges): JSON highlighting with diff colors
  over the embedded `patch` array, plus schema validation and completions.
- `leanreview/config.json` (the config file): schema validation and
  completions — including the full action-name enum for `keys` remaps.

Configs generated by `leanreview --init-config` carry a `$schema` reference,
so they validate even without this extension.

## Install

No marketplace needed — copy the folder into your extensions directory:

```bash
cp -r editors/vscode ~/.vscode/extensions/leanreview-exchange-1.0.0
```

then reload VS Code (`Developer: Reload Window`).

## Schema-only alternative

If you only want validation (keeping the stock JSON language), skip the
extension and add to your `settings.json`:

```json
"json.schemas": [
  {
    "fileMatch": ["*.review.json"],
    "url": "https://perrito666.github.io/leanreview/schema/leanreview-review.schema.json"
  },
  {
    "fileMatch": ["**/leanreview/config.json"],
    "url": "https://perrito666.github.io/leanreview/schema/leanreview-config.schema.json"
  }
]
```
